# AtCoder Sample Visualizer

AtCoder の問題ページで、サンプル入力を「点群」または「(頂点数・辺数)グラフ」として解釈できたときに、見出しの横に「📊 図で見る」ボタンを追加し、座標平面上に描画するブラウザ拡張機能です。

## 機能

- `https://atcoder.jp/contests/*/tasks/*` の問題ページで動作します。
- 各「入力例 N」/「Sample Input N」の見出しを見て、対応する `<pre>` の中身を次の2つの形式で解釈を試みます。
  - **点群**: 1行目が `N`、続く N 行がそれぞれ `X Y`(例: 座標平面上の点の問題)
  - **グラフ**: 1行目が `N M`、続く M 行がそれぞれ `u v` または `u v w`(重み付き)の辺(例: グラフ・木の問題)。頂点番号は 1-indexed / 0-indexed のどちらも自動判定します。
- どちらの形式にも当てはまらないサンプル(配列の問題など)にはボタンを追加しません。
- **点群**は指定された座標をそのままグリッド(目盛り付き)の上にプロットします。
- **グラフ**は座標が与えられていないため、力学モデル(ばね+反発力)による自動レイアウトで見やすい配置を計算します。辺の重みがあれば辺の中央に表示します。自己ループは点線の輪、多重辺(同じ頂点対を結ぶ複数の辺)は湾曲させて重ならないように描画します。
- グラフには「特徴チェックリスト」を併記します: 連結・木構造・閉路・自己ループ・多重辺・二部グラフの有無を一目で確認できます。
- 各点・各辺にマウスを乗せると詳細(座標や頂点番号)がツールチップで見られます。
- パネルはページのテーマ拡張機能や OS のダークモード設定に関わらず、常に白背景で表示します。

## 制限事項

- あくまで簡易的なヒューリスティックです。「N 個の点」「N 頂点 M 辺のグラフ」以外の形式(配列、グリッド、文字列など)には対応していません。
- サンプルの後ろに余分な行(クエリなど)が続いていても、点/辺の部分だけを読み取って描画します。
- 極端に大きい入力(点 2000 個、頂点 300 個/辺 2000 本超)は対象外です。

## インストール

### Chrome / Edge

1. `chrome://extensions` または `edge://extensions` を開きます。
2. デベロッパーモードを有効にします。
3. `パッケージ化されていない拡張機能を読み込む` を押します。
4. このリポジトリ内の `extensions/atcoder-sample-visualizer/` を選択します。

### Firefox

1. `about:debugging#/runtime/this-firefox` を開きます。
2. `一時的なアドオンを読み込む` を押します。
3. このリポジトリ内の `extensions/atcoder-sample-visualizer/manifest.json` を選択します。

## 使い方

拡張機能を読み込んだ状態で AtCoder の問題ページを開き、対応するサンプル入力の見出し横にある「📊 図で見る」を押します。
