# AtCoder Sample Visualizer

AtCoder の問題ページで、サンプル入力を「点群」「(頂点数・辺数)グラフ」「グリッド」のいずれかとして解釈できたときに、見出しの横に「📊 図で見る」ボタンを追加し、座標平面上に描画するブラウザ拡張機能です。

## 機能

- `https://atcoder.jp/contests/*/tasks/*` の問題ページで動作します。
- 各「入力例 N」/「Sample Input N」の見出しを見て、対応する `<pre>` の中身を次の3つの形式で順番に解釈を試みます。
  - **点群**: 1行目が `N`、続く N 行がそれぞれ `X Y`(例: 座標平面上の点の問題)
  - **グラフ**: 1行目が `N M`、続く M 行がそれぞれ `u v` または `u v w`(重み付き)の辺(例: グラフ・木の問題)。頂点番号は 1-indexed / 0-indexed のどちらも自動判定します。
  - **グリッド**: 1行目が `H W`、続く H 行がそれぞれ長さ W の文字列(例: 迷路・盤面の問題)
  - どれにも当てはまらないサンプル(配列の問題など)にはボタンを追加しません。

### 点群

- 座標をグリッド(目盛り付き)の上にプロットします。
- **点を2つか3つクリックすると、2点間の距離、または3点目の頂点での角度(∠P₁P₂P₃)を表示します。** もう一度同じ点をクリックすると選択解除、4点目をクリックすると一番古い選択が外れます。
- 「順番につなぐ(多角形)」にチェックを入れると、入力順に全ての点を結んだ多角形を薄く重ねて表示します。

### グラフ

- 座標が与えられていないため、力学モデル(ばね+反発力)による自動レイアウトで見やすい配置を計算します。
- **木構造と判定できた場合は、根(頂点1)からの階層レイアウトに自動的に切り替わります。**
- 辺の重みがあれば辺の中央に表示します。自己ループは点線の輪、多重辺(同じ頂点対を結ぶ複数の辺)は湾曲させて重ならないように描画します。
- 「有向として表示」にチェックを入れると、各辺に矢印を表示します(入力だけからは有向・無向を判別できないため、手動切り替えです)。
- 頂点にマウスを乗せると、その頂点につながる辺と隣接頂点だけがハイライトされ、それ以外は薄く表示されます。
- 「特徴チェックリスト」を併記します: 連結・木構造・閉路・自己ループ・多重辺・二部グラフの有無を一目で確認できます。

### グリッド

- 各文字を色分けしたマス目として描画します。`#`(壁)と `.`(空き)は固定色、それ以外の文字は自動で色を割り当て、凡例を表示します。

### 共通

- 各点・各辺・各マスにマウスを乗せると詳細(座標・頂点番号・値)がツールチップで見られます。
- パネルはページのテーマ拡張機能や OS のダークモード設定に関わらず、常に白背景で表示します。

## 制限事項

- あくまで簡易的なヒューリスティックです。上記3形式以外(文字列問題など)には対応していません。
- サンプルの後ろに余分な行(クエリなど)が続いていても、該当部分だけを読み取って描画します。
- 極端に大きい入力(点 2000 個、頂点 300 個/辺 2000 本超、グリッド 3000 マス超)は対象外です。
- 有向・無向、根の位置(木は常に頂点1を根とします)は自動判定できないため、必要に応じて表示側で切り替えてください。

## インストール

### Chrome / Edge

1. `chrome://extensions` または `edge://extensions` を開きます。
2. デベロッパーモードを有効にします。
3. `パッケージ化されていない拡張機能を読み込む` を押します。
4. このリポジトリ内の `extensions/atcoder-sample-visualizer/` を選択します。

### Firefox

1. `about:debugging#/runtime/this-firefox` を開きます。
2. `一時的なアドオンを読み込む` を押します。
3. このリポジトリ内の `extensions/atcoder-sample-visualizer/manifest.json` を選択します。

## 使い方

拡張機能を読み込んだ状態で AtCoder の問題ページを開き、対応するサンプル入力の見出し横にある「📊 図で見る」を押します。
