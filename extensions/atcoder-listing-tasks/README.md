# AtCoder Listing Tasks

AtCoder のコンテストページで「問題」タブをドロップダウン化し、コンテスト内の各問題に素早く移動できるようにするブラウザ拡張機能です。
[luuguas/AtCoderListingTasks](https://github.com/luuguas/AtCoderListingTasks) というユーザースクリプトを元に、このリポジトリの拡張機能として作り直したものです。

## 機能

- `https://atcoder.jp/contests/*`(コンテスト一覧・アーカイブページを除く)で動作します。
- 「問題」タブをクリックすると、コンテスト内の全問題への直接リンクを含むドロップダウンが開きます。
- **検索フィルタ**: ドロップダウン上部の検索欄に入力すると、問題名・記号でその場で絞り込めます。問題数が多いコンテストでも目的の問題をすぐに見つけられます。
- **現在地のハイライト**: 問題ページを開いているとき、リスト内の該当する問題に `▸` マークを付けて分かりやすくします。
- **新しいタブで開く**: チェックを入れると、リンクは新しいタブで開くようになります(設定は保存されます)。
- **まとめて開く**: 範囲(または全問題)を選んで、複数の問題を一度に新しいタブで開けます。順序を逆にするオプション付き。一度に開けるタブ数には上限(20個)があります。
- 問題一覧は `chrome.storage.local` に6時間キャッシュされ、再訪時の読み込みを高速化します。

## 元のユーザースクリプトとの違い

- Tampermonkey 等のユーザースクリプトマネージャ不要で、ブラウザ拡張機能として直接読み込めます。
- ドロップダウンの高さ指定が `max-height: 890%`(親要素に高さがないと実質無効になる)だったため、問題数が多いコンテストでリストが画面外まで伸びて途中で見切れる不具合がありました。`70vh` に変更し、スクロールできるようにしました。
- 検索フィルタと現在地ハイライトを新たに追加しました。
- 保存先を IndexedDB から `chrome.storage.local` に簡略化しました。

## インストール

### Chrome / Edge

1. `chrome://extensions` または `edge://extensions` を開きます。
2. デベロッパーモードを有効にします。
3. `パッケージ化されていない拡張機能を読み込む` を押します。
4. このリポジトリ内の `extensions/atcoder-listing-tasks/` を選択します。

### Firefox

1. `about:debugging#/runtime/this-firefox` を開きます。
2. `一時的なアドオンを読み込む` を押します。
3. このリポジトリ内の `extensions/atcoder-listing-tasks/manifest.json` を選択します。

## 使い方

拡張機能を読み込んだ状態で AtCoder のコンテストページを開き、「問題」タブをクリックします。
